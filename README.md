# Simple Past Tense – Interactive English Learning Suite 🇬🇧

Thư viện học và luyện tập toàn diện về **Thì Quá Khứ Đơn (Simple Past Tense)** với 10 module tương tác sinh động, sơ đồ tư duy, hệ thống bài tập trắc nghiệm, game ghép câu hỏi và âm thanh giọng đọc bản xứ.

---

## 🚀 Cách Sử Dụng

1. Clone hoặc tải kho lưu trữ về máy tính:
   ```bash
   git clone https://github.com/vanlavang/simple-past.git
   ```
2. Mở file **`index.html`** hoặc **`SIMPLE PAST.html`** bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Cốc Cốc, Safari...).
3. Không yêu cầu cài đặt server hay internet: Toàn bộ dữ liệu, giao diện, script và âm thanh hoạt động **100% offline**.

## 🛠 Công Nghệ Sử Dụng
- **HTML5 / CSS3 / JavaScript** thuần (Vanilla JS, không phụ thuộc framework).

- **Responsive Design** tương thích tốt trên máy tính, máy chiếu trường học, tablet và smartphone.
